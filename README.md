# Acronym Lookup Chrome Extension

A lightweight, custom Google Chrome extension that allows you to quickly look up acronym definitions directly from your browser toolbar. If an acronym is not found in the local database, the extension provides a quick Google search link and options to request its addition.

## Features
* **Quick Search:** Look up acronyms instantly via the popup interface.
* **Web Fallback:** Automatically generates a Google search link for unknown acronyms.

## Installation Instructions

Follow these steps to install the extension manually in Google Chrome:

1. **Download the Files:** Download or clone this project to your local machine.
2. **Open Chrome Extensions:** Open Google Chrome and type `chrome://extensions/` into the address bar, then press `Enter`.
3. **Enable Developer Mode:** Toggle on the **Developer mode** switch located in the top right corner of the extensions page.
4. **Load the Extension:** Click the **Load unpacked** button that appears in the top left corner of the page.
5. **Select the Folder:** Navigate to the folder where you saved the extension files, select it, and click **Select Folder** (or **Open**).

## Usage

1. Click the puzzle piece icon (Extensions menu) in the top right of your Chrome browser.
2. Click the **Pin** icon next to the extension to keep it visible in your toolbar.
3. Click the extension icon to open the popup.
4. Type an acronym (e.g., "API") and press `Enter` or click **Search**.
